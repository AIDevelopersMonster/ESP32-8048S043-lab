# Contributing

This repository accepts evidence, documentation and code, but hardware claims must be conservative.

## Rules

- Do not mark a subsystem as PASS without a named specimen and reproducible evidence.
- Separate OBSERVED, VERIFIED and REPORTED ONLY.
- Do not commit personal Wi-Fi credentials, MAC addresses unless intentionally public, private keys or local build products.
- Do not copy third-party firmware, vendor archives or images unless redistribution is permitted.
- Failed experiments may be documented, but the current status table must reflect the current validated state.
