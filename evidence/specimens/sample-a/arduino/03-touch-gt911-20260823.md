
```text

GT911 point data register   0x814F
I2C SDA/SCL                 GPIO19 / GPIO20
GT911 reset                 GPIO38
GT911 INT                   GPIO18, passive pull-up only / no interrupt dependency
Backlight                   GPIO2 HIGH
Display path                Arduino_GFX RGB 800x480
```

## Notes

The log includes repeated lines such as:

```text
Touch status unusual: 0x80 points=0
```

For this PASS they are treated as non-fatal. They indicate a data-ready bit with zero touch points and should be quieted in a later cleanup by clearing `0x814E` without printing repeated warnings.

The GT911 resolution/config registers reported:

```text
X=480 Y=272
```

This does not invalidate the test. The observed raw coordinate range is compressed and is mapped to the physical `800x480` display by the current calibration seed. Final LVGL calibration remains a separate task.
