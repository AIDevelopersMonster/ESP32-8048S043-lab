## Working conclusions

1. `app0` contains the useful factory application.
2. The application identity strongly points to `LVGL Widgets Demo`.
3. The display path strongly points to `Arduino_GFX` + `Arduino_ESP32RGBPanel` + ESP-IDF RGB panel driver.
4. I2C driver support is present, but touch controller identity is still unresolved.
5. Factory diagnostic/test mode remains unproven.
6. Exact pin mapping must still be validated physically or recovered from deeper binary analysis.

## Boundary

This is static string evidence only. It can guide the first lab firmware choices, but it cannot be used as a physical PASS for RGB display, touch, backlight or pin mapping.
