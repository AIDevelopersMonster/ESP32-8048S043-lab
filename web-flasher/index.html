ESP32-8048S043 — Six-Card Serial Deck

Browser installer for the current physically validated App 01 firmware demonstrated on the real ESP32-8048S043 board.

Use a Chromium browser with Web Serial support, such as Chrome or Edge. This installer must be opened from the HTTPS GitHub Pages site.

What this firmware demonstrates

  • HOME / MEDIA / SYSTEM profile switching
  • six profile-driven touch cards
  • GT911 touch input
  • 800×480 LVGL 9 interface
  • PROFILE: and CARD: commands over Serial/COM

Target hardware: the physically validated ESP32-8048S043 ESP32-S3 800×480 / GT911 board profile used by this repository. Installing replaces the current firmware on the connected board.
