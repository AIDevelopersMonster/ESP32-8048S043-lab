APPLICATION HELP / SERIAL LAB-02

Interactive Serial Terminal

Второй шаг Serial-линии KONTAKTS: теперь произвольную команду можно набрать прямо на TFT штатной LVGL 9 клавиатурой и отправить через UART0.

Platform ≥ 0.3.7 Widget 0.1.0 115200 · 8N1 PHYSICAL TEST PENDING
Help Center Пользователь Прикладной программист GitHub

Что нового относительно USB Serial Monitor

Input
textarea

Редактируемое поле ввода создаётся из JSON, а не жёстко в прошивке приложения.

Keyboard
LVGL 9 keyboard

Экранная клавиатура привязывается к textarea по идентификатору target.

Action
serial_send_text

Кнопка SEND передаёт текущее содержимое выбранного textarea через общий serial service.

Архитектура

LVGL keyboard→ textarea→ serial_send_text→ serial service→ UART0→ CH340C→ PC
Почему это SD-приложение В прошивку добавлены только универсальные возможности textarea, keyboard и generic serial action. Конкретная компоновка терминала остаётся обычным JSON-пакетом на SD.

Быстрый тест

Установите KONTAKTS Platform 0.3.7 или новее.
Скопируйте каталог widgets/serial-terminal на SD и нажмите REFRESH.
Откройте Interactive Serial Terminal.
Наберите на TFT, например, HELLO123 и нажмите SEND.
На PC в KONTAKTSerial должна появиться строка HELLO123 с окончанием CRLF.

Новые Widget Runtime primitives

PrimitiveОсновные свойстваНазначение
textareaid, text, placeholder, max_length, one_lineРедактируемый текстовый ввод.

Пример JSON

{
  "type": "textarea",
  "id": "tx_input",
  "x": 16, "y": 158, "w": 530, "h": 46,
  "placeholder": "Type command...",
  "max_length": 128,
  "one_line": true
},
{
  "type": "keyboard",
  "x": 16, "y": 214, "w": 712, "h": 140,
  "target": "tx_input"
},
{
  "type": "button",
  "text": "SEND",
  "action": "serial_send_text",
  "target": "tx_input"
}

Текущая граница

LAB-02, не LAB-03 Пока используется стандартная LVGL keyboard, одна строка ввода и фиксированное окончание CRLF. История команд, выбор None/LF/CR/CRLF, ASCII/HEX и специальная клавиатура относятся к следующему Serial-виджету.
