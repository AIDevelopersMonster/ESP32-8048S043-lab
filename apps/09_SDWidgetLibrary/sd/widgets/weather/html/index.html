APPLICATION HELP

Weather

Help Center

Первый пакет Weather создан как демонстрация появления нового приложения в SD launcher без изменения firmware.

Текущий статус

DEMO DATA. Значения в текущей версии статические. Пакет пока не является источником реальной погоды.

Экраны

  • Current Weather
  • Today
  • 7 Day Forecast

Следующий этап

Для живых данных нужен platform-level weather/HTTP JSON provider. Он должен быть общим сервисом, а не кодом, жёстко встроенным под один Weather widget. После появления такого provider интерфейс Weather снова останется SD-пакетом.

Установка

SD:\widgets\weather\

Скопируйте каталог и нажмите REFRESH. Новый application card появляется из manifest-driven каталога.
