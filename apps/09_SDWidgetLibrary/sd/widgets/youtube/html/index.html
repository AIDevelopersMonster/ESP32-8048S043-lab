APPLICATION HELP

YouTube

Help Center

Пакет экранов статистики YouTube для KONTAKTS Platform.

Экраны

  • YouTube Dashboard — основные показатели и графики.
  • YouTube Views — отдельный график просмотров.
  • YouTube Subscribers — отдельный график подписчиков.

Зависимость

Требуется platform service youtube. API key хранится в NVS и не должен лежать на SD.

Настройка

В браузере откройте http://IP-ПЛАТЫ/youtube. Там задаются Channel ID и API key, запускается обновление и выбирается период истории.

Установка

SD:\widgets\youtube\

После копирования каталога нажмите REFRESH в SD launcher.
