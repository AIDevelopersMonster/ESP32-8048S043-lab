YouTube LED Carousel

Help Center

Демонстрация generic UI capability metric_carousel.

Что показывает

SUBSCRIBERS → 5 s
VIEWS       → 5 s
VIDEOS      → 5 s
TIME        → 5 s
repeat

Пакет использует существующие youtube и time services. Firmware не содержит YouTube-специфический carousel launcher.

Почему это важно

metric_carousel был добавлен как общая возможность платформы. После этого данный application package устанавливается только копированием каталога на SD.

Physical pass

Пакет был запущен на реальной ESP32-8048S043, а значения циклически переключались каждые 5 секунд.
