USB Serial Terminal

SD-виджет для проверки и использования штатного последовательного канала ESP32-8048S043 через onboard CH340C и UART0.

Help CenterРуководство пользователя

Что проверяет виджет

PC -> USB -> CH340C -> UART0 -> ESP32-S3 -> Widget Runtime -> TFT
PC <- USB <- CH340C <- UART0 <- ESP32-S3 <- Widget Runtime <- TFT

Это первая стадия UART-лаборатории. Разъём P1 в данный тест не входит и продолжает рассматриваться отдельно как сервисный UART0-разъём.

Требования

  • KONTAKTS Platform 0.3.5 или новее;
  • SD-пакет widgets/usb-serial-terminal;
  • обычный USB data-кабель к плате;
  • COM-порт 115200 8N1, flow control выключен.

Работа с KONTAKTSerial

Для Windows в репозитории есть наш лёгкий терминал KONTAKTSerial. Он не требует ESP-IDF и использует Python + pyserial.

python -m pip install pyserial
python .\tools\KONTAKTSerial\KONTAKTSerial.py --port COMxx --baud 115200

Выберите реальный COM-порт платы. Перед подключением закройте другие программы, которые уже держат этот COM-порт.

Проверка PC → TFT

  1. Откройте USB Serial Monitor на дисплее.
  2. Подключите KONTAKTSerial к COM-порту на 115200.
  3. Отправьте строку, например HELLO123, с окончанием CRLF.
  4. Строка должна появиться в RX-области TFT, а счётчик RX увеличиться.

Проверка TFT → PC

Нажмите SEND TEST на TFT. В KONTAKTSerial должна появиться строка:

KONTAKTS USB SERIAL TEST

Кнопка CLEAR очищает RX-буфер виджета и его счётчики.

Текущие ограничения

  • в этой версии на TFT ещё нет экранной клавиатуры и textarea для произвольного ввода;
  • UART0 одновременно является console/logging path, поэтому в PC-терминале видны системные сообщения ESP-IDF;
  • виджет не подтверждает безопасное применение P1 как пользовательского UART при других режимах подключения.

Следующий этап — добавить в общий Widget Runtime generic textarea и keyboard, после чего терминал сможет отправлять произвольные команды прямо с дисплея.
