USB Serial Terminal

Один SD-пакет для UART0 через штатный USB/CH340C. Внутри два экрана: проверенный USB Serial Monitor и Interactive Serial Terminal с textarea, экранной LVGL-клавиатурой и SEND.

Граница этого PASS Разъём P1 в данный тест не входит. Здесь проверен только штатный путь USB ↔ CH340C ↔ UART0.

Быстрый запуск

На вкладке SD откройте USB Serial Terminal. Внутри выберите USB Serial Monitor либо Interactive Serial Terminal.
Подключите плату обычным USB data-кабелем. В Windows появится COM-порт CH340C.
Откройте KONTAKTSerial. Выберите COM-порт платы и скорость 115200.
Проверьте оба направления. Отправьте HELLO123 с PC, затем нажмите SEND TEST на TFT.

KONTAKTSerial на компьютере

Установка зависимости 
python -m pip install pyserial

ESP-IDF для работы терминала не требуется.

Запуск 
python .\tools\KONTAKTSerial\KONTAKTSerial.py --port COMxx --baud 115200

Вместо COMxx укажите реальный порт платы.

Проверка PC → TFT

Убедитесь, что на TFT открыт USB Serial Monitor.
В KONTAKTSerial нажмите Connect.
Выберите окончание строки CRLF и отправьте HELLO123.
На TFT должна появиться строка HELLO123, а значение RX bytes должно увеличиться.

Проверка TFT → PC

Оставьте KONTAKTSerial подключённым к COM-порту.
На TFT нажмите SEND TEST.
На компьютере должна появиться строка:
KONTAKTS USB SERIAL TEST

Почему в терминале видны системные логи

UART0 одновременно используется как console/logging path ESP-IDF. Поэтому рядом с пользовательскими данными KONTAKTSerial может показывать строки вида:

I (...) APP09_UI: UI stack high-water=...
I (...) APP05_NET: STA online ip=...

Для текущего Stage 1 это ожидаемое поведение, а не ошибка терминала.

Если что-то не работает

СимптомПроверить
COM-порт не открываетсяЗакройте Serial Monitor, miniterm, Arduino IDE и другие программы, которые могут держать этот COM-порт.
После Connect плата перезагрузиласьНекоторые host-terminal настройки DTR/RTS могут вызвать reset через USB-UART. После загрузки соединение обычно продолжает работать.
PC отправляет, а TFT молчитПроверьте, что открыт именно USB Serial Monitor и выбран правильный COM-порт на 115200.
На PC много строк ESP-IDFЭто нормально: UART0 сейчас общий для console logging и serial service.
SEND TEST не приходитПроверьте, что KONTAKTSerial остаётся подключён к тому же COM-порту.
