USB Serial Terminal

Stage 1 tests the normal ESP32-8048S043 USB serial path through the onboard CH340C and UART0.

PC -> USB -> CH340C -> UART0 -> ESP32-S3 -> TFT

Open the board COM port at 115200 baud. Text typed on the PC should appear in the RX area.

Press SEND TEST on the TFT. The PC should receive KONTAKTS USB SERIAL TEST.

CLEAR resets the displayed RX buffer and the widget counters.

This first version intentionally has no on-screen keyboard. Keyboard and textarea support are the next generic Widget Runtime capabilities after the bidirectional path passes on hardware.

P1 is not part of this first test.
