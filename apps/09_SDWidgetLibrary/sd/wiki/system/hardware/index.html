Разъёмы и интерфейсы

  • USB / serial programming: board reconstruction identifies CH340C. The exact external connector and any exposed header pins must be checked against the physical specimen/revision before electrical use.
  • TF / microSD slot: SD is operated in SPI mode on GPIO10–13.
  • LCD + touch: LCD uses the RGB parallel bus; GT911 uses I²C. These paths have own physical runtime PASS on Sample A.

Неизвестные pin-header/power-connector labels не объявляются VERIFIED только по предположению. Добавляем их сюда после фото/схемы/измерения конкретной ревизии платы.
