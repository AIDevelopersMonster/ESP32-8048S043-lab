Главное правило

Совместимое приложение должно устанавливаться копированием каталога на SD без добавления C-кнопки и без пересборки firmware. Новая прошивка требуется только если приложению не хватает общего platform service/provider/driver/UI capability.

Пакет

widgets/my-app/
├── package.json
├── main.json
├── optional-screen.json
└── html/
    └── index.html

На физическом уровне имя каталога ограничено ASCII-символами A-Z a-z 0-9 . _ -.

package.json

{
  "schema": 1,
  "id": "my-app",
  "name": "My App",
  "version": "1.0.0",
  "type": "widget-package",
  "entrypoints": [
    {"id":"main","name":"Main","file":"main.json"}
  ],
  "requires": {
    "minimum_platform": "0.3.3",
    "services": ["time"]
  },
  "documentation": {
    "entry": "html/index.html"
  },
  "firmware": {"required": false}
}

Entry points

Только элементы массива entrypoints появляются как экраны приложения на дисплее. Служебные JSON-файлы не становятся кнопками автоматически.

Widget Runtime

Текущий runtime понимает объекты label, bar, button, clock, chart, metric_carousel, а начиная с Platform 0.3.7 также generic textarea и keyboard. Выбранный SD JSON валидируется и сохраняется в /storage/widget.json.

textarea

{
  "type":"textarea",
  "id":"tx_input",
  "x":16, "y":158, "w":530, "h":46,
  "placeholder":"Type command...",
  "max_length":128,
  "one_line":true
}

id обязателен и уникален внутри документа. max_length допустим от 1 до 256 символов.

keyboard

{
  "type":"keyboard",
  "x":16, "y":214, "w":712, "h":140,
  "target":"tx_input"
}

target должен ссылаться на существующий textarea.id. Runtime создаёт стандартную LVGL 9 keyboard и привязывает её к этому полю.

Доступные bindings

Набор включает system/Wi-Fi/firmware/OTA, time, YouTube и начиная с платформы 0.3.5 serial bindings:

serial.rx_text
serial.rx_bytes
serial.tx_bytes
serial.state

Serial-приложения используют действия:

serial_send_test
serial_send_text
serial_clear

serial_send_text применяется у button с обязательным target, указывающим на textarea. Текущее содержимое поля передаётся через общий serial service с окончанием CRLF.

Приложение не должно придумывать binding или action, который платформа ещё не предоставляет.

Services и capabilities

Приложение объявляет зависимости на абстрактные сервисы: например time, youtube и serial; в будущем возможны weather, temperature, relay, flow-meter. Конкретный датчик или драйвер остаётся задачей platform provider.

Пример для serial-приложения:

"requires": {
  "minimum_platform": "0.3.5",
  "services": ["serial"]
}

На текущем этапе SD Manager ещё не блокирует запуск по minimum_platform и requires.services; это декларация зависимости и документация совместимости, а не полноценный runtime gate.

HTML-справка

Поместите документацию в html/index.html и объявите её через documentation.entry. Она появится в browser Help Center, но никогда не попадёт в LVGL launcher.

HTML help запускается с жёстким Content Security Policy: без JavaScript, форм, iframe и сетевых запросов. Это справка, а не способ получить доступ к системным HTTP API.
