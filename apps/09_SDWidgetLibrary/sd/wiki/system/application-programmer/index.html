Главное правило

Совместимое приложение должно устанавливаться копированием каталога на SD без добавления C-кнопки и без пересборки firmware. Новая прошивка требуется только если приложению не хватает общего platform service/provider/driver/UI capability.

Пакет

widgets/my-app/
├── package.json
├── main.json
├── optional-screen.json
└── html/
    └── index.html

На физическом уровне имя каталога ограничено ASCII-символами A-Z a-z 0-9 . _ -.

package.json

{
  "schema": 1,
  "id": "my-app",
  "name": "My App",
  "version": "1.0.0",
  "type": "widget-package",
  "entrypoints": [
    {"id":"main","name":"Main","file":"main.json"}
  ],
  "requires": {
    "minimum_platform": "0.3.3",
    "services": ["time"]
  },
  "documentation": {
    "entry": "html/index.html"
  },
  "firmware": {"required": false}
}

Entry points

Только элементы массива entrypoints появляются как экраны приложения на дисплее. Служебные JSON-файлы не становятся кнопками автоматически.

Widget Runtime

Текущий runtime понимает объекты label, bar, button, clock, chart и metric_carousel. Выбранный SD JSON валидируется и сохраняется в /storage/widget.json.

Доступные bindings

Текущий набор включает system/Wi-Fi/firmware/OTA, time и YouTube bindings. Приложение не должно придумывать binding, который платформа ещё не предоставляет.

Services и capabilities

Приложение объявляет зависимости на абстрактные сервисы: например time, youtube, в будущем weather, temperature, relay, flow-meter. Конкретный датчик или драйвер остаётся задачей platform provider.

HTML-справка

Поместите документацию в html/index.html и объявите её через documentation.entry. Она появится в browser Help Center, но никогда не попадёт в LVGL launcher.

HTML help запускается с жёстким Content Security Policy: без JavaScript, форм, iframe и сетевых запросов. Это справка, а не способ получить доступ к системным HTTP API.
