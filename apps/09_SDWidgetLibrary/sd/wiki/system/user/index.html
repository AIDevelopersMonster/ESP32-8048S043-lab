1. Что это

KONTAKTS Platform — прошивка для ESP32-8048S043 с тремя основными областями на дисплее: SYS | SD | WIDGET. Приложения могут храниться на SD и запускаться через Widget Runtime.

2. Прошивка с Windows

Для полного BIN используйте вспомогательный ESP32 BIN Flasher v2 из репозитория. Для нашей платы выбран ESP32-S3, адрес полного образа обычно 0x0. Загрузчик не выполняет erase-flash автоматически.

python -m esptool --chip esp32s3 --port COMxx --baud 921600 write-flash 0x0 firmware.bin

3. Wi-Fi

После первого запуска платформа поднимает setup AP, если сохранённых параметров сети нет. После подключения к домашней сети IP платы отображается в SYS и используется для web-интерфейса.

4. SD-приложения

SD:\widgets\youtube\
SD:\widgets\clock\
SD:\widgets\youtube-led\
SD:\widgets\weather\

Скопируйте совместимый пакет в widgets, вставьте SD и нажмите REFRESH на вкладке SD. Платформа читает package.json и строит каталог автоматически.

5. Справка

С телефона или компьютера откройте http://IP-ПЛАТЫ/help. Экран ESP32 для длинной документации не используется.

6. OTA и восстановление

GitHub OTA, CONFIRM, ROLLBACK и FACTORY RECOVERY находятся в SYS. Не отключайте питание во время записи новой прошивки. После OTA новая версия должна пройти обычный цикл подтверждения.

7. Что сейчас ещё проверяется

  • явное извлечение SD после запуска и работа сохранённого widget;
  • перезагрузка без SD с восстановлением сохранённого widget;
  • полный offline update из /SD/UPDATE.

Отсутствие SD не должно лишать пользователя SYS/recovery. Это архитектурный инвариант проекта.
