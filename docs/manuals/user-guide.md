## 1. Назначение устройства

Краткое описание платформы и принципа работы: базовые системные функции находятся в прошивке, а прикладной экран WIDGET может загружаться отдельно из внутренней файловой системы.

## 2. Органы управления и экран

### Основные системные вкладки

```text
STATUS | OTA | WIDGET
```

- `STATUS` — состояние устройства, сети, версии и раздела прошивки;
- `OTA` — проверка/установка firmware, CONFIRM, ROLLBACK, recovery;
- `WIDGET` — установленный прикладной экран из файловой системы.

## 8. Сохранность данных

Объяснить пользователю простыми словами:

- Wi-Fi credentials хранятся отдельно от app OTA;
- widget хранится в `storage` отдельно от app OTA;
- обычный reset не должен удалять widget;
- полный сервисный flash может иметь другой эффект и не является обычной пользовательской операцией.

## 10. Типовые неисправности

Будущая таблица:

| Симптом | Что проверить | Действие пользователя | Когда нужен системный программист |
|---|---|---|---|
| Не подключается Wi-Fi | SSID/пароль/режим AP | повторить provisioning | повторяющиеся reset/errors |
| CHECK GITHUB выдаёт ошибку | интернет/сеть | повторить после восстановления связи | TLS/memory error в serial |
| Widget не принимается | JSON/версия schema | выбрать корректный файл | корректный файл стабильно reject |
| Widget пустой после reset | наличие install PASS | установить повторно | autoload failure |
| После update вернулась старая версия | был ли CONFIRM | установить снова и CONFIRM | rollback происходит после CONFIRM |

## 11. Безопасность действий

- не отключать питание во время firmware write без необходимости теста;
- не использовать случайные/непроверенные widget JSON в ответственных установках;
- не публиковать Wi-Fi пароль;
- destructive recovery/service procedures выполнять только по отдельной инструкции.

## 13. Каталог прикладных виджетов

Эта глава **не должна превращаться в одно огромное руководство**. Каждый виджет получает отдельный подраздел/файл по шаблону `widget-user-section-template.md`.

Рекомендуемая структура:

```text
docs/manuals/widgets/
  README.md
  platform-status.md
  second-widget-demo.md
  weather.md
  camera.md
  relay-control.md
  ...
```

Основное руководство содержит только индекс и общие правила установки.
