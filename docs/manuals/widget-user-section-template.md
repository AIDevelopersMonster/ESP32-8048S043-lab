## 3. Требования

- минимальная версия firmware/runtime;
- требуемая schema;
- требуется ли Wi-Fi/интернет/внешний сервис;
- дополнительные аппаратные требования.

## 4. Установка

1. Открыть web UI устройства.
2. Выбрать `<widget-file>.json`.
3. Нажать `UPLOAD & INSTALL WIDGET`.
4. Проверить `INSTALL PASS`.
5. Открыть вкладку `WIDGET`.
