# Visitor hardware validation

Visitors can report boards without knowing Git.

1. Photograph both sides of the board.
2. Run the passive audit script.
3. Open a GitHub issue using the board report template.
4. Attach photos and the generated `.txt` report.
5. Remove or redact MAC addresses if you do not want them public.

No PASS claim is created from a visitor report until the evidence is reviewed and categorized.
